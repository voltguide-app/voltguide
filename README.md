# ⚡ VoltGuide

L'assistant de poche de l'électricien, basé sur la NF C 15-100.

- 🏠 **Guide pièce par pièce** : le minimum obligatoire (prises, éclairage, circuits spécialisés)
- 🧮 **Calculateurs** : générateur de tableau électrique, éclairage (lux), section de câble et chute de tension, différentiels, bilan de puissance, loi d'Ohm
- 📚 **Fiches** : schémas de câblage, différentiels, habilitations, IRVE, photovoltaïque, liseré des câbles R2V, indices IP…
- 📋 **Carnet de chantier** : mesures, test des différentiels, photos, rapport
- ✅ **Check-list** d'autocontrôle avant le Consuel

L'application fonctionne sur téléphone et ordinateur, même sans réseau une fois installée.

## Installer l'application sur son téléphone

- **Android (Chrome)** : ouvrir le site, puis menu ⋮ → **Installer l'application**
- **iPhone (Safari)** : ouvrir le site, puis bouton Partager → **Sur l'écran d'accueil**

## ⚠️ Avertissement

VoltGuide est une aide. Elle ne remplace pas la norme NF C 15-100 officielle.
Les règles marquées « À vérifier » n'ont pas encore été relues par un professionnel.
